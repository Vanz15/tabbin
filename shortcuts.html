Keyboard shortcuts

Text formatting

Ctrl+BBold
Ctrl+IItalic
Ctrl+UUnderline
Ctrl+Alt+SStrikethrough
Ctrl+LAlign left
Ctrl+EAlign centre
Ctrl+RAlign right

Lists and to-dos

1. then SpaceStart a numbered list
- then SpaceStart a bulleted list
[] then SpaceStart a to-do item
EnterNew line, or the next item in a list
TabIndent a list item
Shift+TabOutdent a list item
Ctrl+EnterCheck or uncheck the current to-do
Backspace at line startRemove a to-do marker; on an empty item, delete it

Notes and the dock

EscClose the font or colour menu; leave fullscreen
Win+.Open the Windows emoji picker in the note or title
Ctrl+KOpen the dock's search field

Shortcuts in the formatting and list sections apply while the note editor has focus. The Windows emoji picker is provided by Windows and works in any text field.

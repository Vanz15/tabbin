# Tabbin — Pre-Beta Scope

Tabbin is a lightweight, hover-activated workspace for organizing quick notes without interrupting the user’s workflow. This release is version **1.0.0-beta.1**, published by **Vanz15**, and intended for private testing before public distribution.

The release includes the transparent auto-hide dock, colored note tabs, rich-text note editing, drag-to-reorder notes, native-resizable note windows, invisible content scrollbars, and the supplied Tabbin application icon. The dock adapts its height and position to the primary display’s work area.

The Settings window was removed from the release because it was not reliable. Dock behavior uses safe defaults and persisted configuration internally. The portable executable and Windows installer are both produced without code signing. The installer creates Start Menu and Desktop shortcuts and asks during uninstall whether to preserve notes and settings or remove all Tabbin data.

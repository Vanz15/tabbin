## Tabbin v1.0.0-beta.1 — Soft Launch

This is the first beta release of Tabbin, a lightweight hover-activated dock for quick notes. Perfect for your daily workflow.

### What's Included

- Transparent auto-hide dock (appears on left screen edge hover)
- Always-on-top behavior (works above fullscreen apps)
- Rich-text note editor with color-coded tabs
- Drag-to-reorder tabs
- Per-note pinning (stay-on-top notes)
- Auto-update capability (GitHub releases)

### Installation Options

- **Tabbin-Portable.exe** — No installation required, just run it!
- **Tabbin-Setup.exe** — Traditional installer with Start Menu shortcut

### Known Issues

- Currently Windows-only (macOS/Linux builds coming soon)
- Settings window disabled (safe defaults used internally)
